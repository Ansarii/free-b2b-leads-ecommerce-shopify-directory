## Dataset Summary & Schema

Every record contains verified business profile data parsed and checked for inbox delivery:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `company_name` | String | Commercial business or brand name |
| `website` | URL | Verified live domain |
| `contact_email` | String | Verified direct contact email address |
| `category` | String | Industry vertical (e.g. Apparel, Beauty, B2B Marketing, Home Goods) |
| `country` | String | Primary country code (US, UK, CA) |

## Quickstart & Sample Usage

Clone this repository and inspect the included 200-record sample datasets:

```bash
git clone https://github.com/Ansarii/free-b2b-leads-ecommerce-shopify-directory.git
cd free-b2b-leads-ecommerce-shopify-directory
```

### Search and Filter Leads via Python CLI

Use the included utility `scripts/filter_leads.py`:

```bash
# Filter Shopify brands by keyword
python3 scripts/filter_leads.py --file data/shopify_brands_sample_200.csv --keyword "boutique"

# Filter agencies by category
python3 scripts/filter_leads.py --file data/marketing_agencies_sample_200.csv --keyword "media"
```
